## 录音参数

- 引擎：豆包语音合成 2.0（`seed-tts-2.0`），音色 `zh_female_vv_uranus_bigtts`
- 东北话：`additions = {"explicit_dialect":"dongbei"}`
- 语气指令：活泼轻快、像朋友开心提醒、带一点俏皮；东北话版为“用东北口音，语气活泼爽朗，像东北朋友唠嗑”
- 选择句额外指令：`『选哪个』这三个字要重读、放慢，像在追问对方`
- 输出：24 kHz / 单声道 / 64 kbps MP3，WAV 为同参数 PCM
